```
│ ┌───────────────────┐ │ ┌────────────────────────────────────────┐ │
│ │ 听损等级 (Select)  │ │ │ ProductCard                             │ │
│ │ 预算区间 (Slider)  │ │ │ [图] 名称  价格  评分(★4.6/320)        │ │

│ │ 外观偏好 (Radio)   │ │ │ 理由:                                   │ │

│ └───────────────────┘ │ │  - 听损匹配：适合中度                     │ │
│                         │ │  - 预算匹配：落在目标区间                 │ │

│                         │ └────────────────────────────────────────┘ │
└───────────────────────┴────────────────────────────────────────────┘
```

### 1.2 关键交互流程
```mermaid
flowchart TD
  A[进入推荐页] --> B[填写画像/选择示例配置]
  B --> C[提交 /api/recommendations/v2]
  C --> D{返回结果?}
  D -->|有| E[渲染商品卡 + FitScore + reasons/warnings]
  D -->|无| F[空态：提示调整画像 + 示例按钮]
  E --> G[点击加入购物车]
  E --> H[点击咨询顾问]
  G --> I[埋点 reco_add_to_cart]
  H --> J[创建咨询 session]
```

## 2) Tele-Audio 咨询与试戴任务

### 2.1 线框（商品详情侧栏）
```
┌─────────────────────────────────────┐
│ 咨询顾问（在线）                     │
│ [开始咨询]  [创建试戴任务]           │
│ 提示：建议仅作选购参考，不构成诊断    │
└─────────────────────────────────────┘
```

### 2.2 流程
```mermaid
sequenceDiagram
  participant U as User
  participant FE as Frontend
  participant API as Backend
  U->>FE: 点击“开始咨询”
  FE->>API: POST /api/consult/session
  API-->>FE: session_id
  U->>FE: 发送消息/选择结构化字段
  FE->>API: POST /api/consult/message
  API-->>FE: ack
  U->>FE: 点击“创建试戴任务”
  FE->>API: POST /api/tryon/create
  API-->>FE: task_id + 状态 created
```
