## 1. 范围与现状

### 1.1 当前图标来源

- 主体：lucide-vue-next（SVG 线性图标，常见用法为 `<Icon class="h-5 w-5" />`）
- 少量：Element Plus 组件内置图标（如 el-alert 的 show-icon），项目未显式引入 element-plus icons
- 业务图片：`<img>` 为商品图/插画，不纳入“图标体系”

### 1.2 样式单调的具体表现（现状问题）

- 颜色：大多数图标仅使用纯色 `currentColor`，缺少层次与品牌强调（尤其在深色主题里“灰白一片”）
- 线条：几乎全为固定 stroke-width，缺少粗细变化与交互反馈，导致“点击感/科技感”不足
- 光效：缺少 hover/focus 的阴影/辉光，交互状态不明显
- 变体：缺少线性/双色/面性（duotone）等风格变体策略，导致信息层级表达能力弱
- 状态：默认/悬停/禁用缺少系统化差异，组件各自定义不一致风险高

## 2. 设计目标（原则）

- 语义清晰：任何增强不得降低辨识度（轮廓优先、对比度优先）
- 系统一致：与现有 tokens（`--c-*`、暗黑模式、HC 高对比）协调一致
- 低侵入：优先全局 CSS 统一覆盖，减少逐组件改动成本
- 可扩展：提供可选的“duotone 容器”“bold/micro stroke”变体类

## 3. 图标样式规范（设计系统）

### 3.1 Token（CSS 变量）

统一从 tokens 中取值（见 `frontend/src/styles/abstracts/_tokens.scss`）：

- `--icon-fg`：默认图标前景色（跟随主题）
- `--icon-muted`：弱化/禁用色（跟随主题）
- `--icon-accent` / `--icon-accent-2`：交互强调色（neon / electric）
- `--icon-stroke`：基础线宽（默认 2）
- `--icon-glow-neon` / `--icon-glow-electric`：辉光颜色（用于 drop-shadow）

### 3.2 状态（默认/悬停/禁用）

- 默认：`stroke=currentColor`，颜色为 `--icon-fg`
- 悬停/可交互：颜色切换为 `--icon-accent`，叠加双层 drop-shadow（neon/electric），轻微上浮 `translateY(-1px)`，线宽增加 `+0.2`
- 禁用：颜色切为 `--icon-muted`，取消滤镜与位移，降低透明度到 0.55

### 3.3 风格变体（按需使用）

- `icon-wrap icon-wrap--duotone`：用于“图标容器”场景（如信任卡片/入口卡片）
  - 容器叠加双层 radial-gradient，形成双色氛围但不改变图标语义
- `icon--bold`：加强线宽（用于强调型图标，如关键 CTA）
- `icon--micro`：减细线宽（用于小尺寸标签/Chip 内的图标）

## 4. 落地文件与使用说明

### 4.1 样式文件

- 全局图标样式：`frontend/src/styles/components/_icons.scss`
- 引入入口：`frontend/src/styles/app.scss`

### 4.2 推荐用法（示例）

- 普通 icon（无需改动）：lucide 图标将被全局样式自动增强
- duotone 容器：
  - 给图标外层容器增加 `icon-wrap icon-wrap--duotone`（例：HomeTrustTiles 已更新）
- 小号标签图标：
  - 外层加 `icon--micro`（在 chip/tag 内建议）

## 5. 兼容性与可访问性

- 使用的 CSS 特性：`filter: drop-shadow`、渐变背景、`transition`，在 Chrome/Edge/Firefox/Safari 主流版本均支持
- `prefers-reduced-motion: reduce`：项目已有全局降动效处理，图标动效会自动降级为近似“无动画”
- `html.hc` 高对比：已关闭辉光，保证对比度优先

## 6. 验收清单

- 图标在 light/dark/hc 三种主题下清晰可辨
- 可交互图标 hover/focus 状态明显且不刺眼
- 禁用态图标弱化明显且不误导为可点击
- 首页导购信任卡片的图标容器呈现双色氛围且不影响布局
