- 前端首页 Lighthouse（desktop）Performance 达到 95（≥90），并固化为可在 CI 里自动校验的门槛。

- npm audit 与 pip-audit 均可在自动化流程中执行并作为门禁。

## 本轮关键改动

### 首屏性能

- 首页加载态去除 Element Plus Skeleton，改为轻量骨架屏，避免首屏引入 Element Plus 运行时代码与样式。
- 所有商品占位图改为本地静态资源，避免外链图片域名导致的 LCP/预连接/缓存策略扣分与不确定性。
- 首页 SSE 初始化延后到空闲阶段，降低关键渲染路径期间的网络与主线程竞争。

### 工程化与门禁

- 新增 GitHub Actions 工作流：后端测试+覆盖率+pip-audit，前端测试+覆盖率+npm audit+Lighthouse，并上传产物为 artifact。
- 新增 Lighthouse 阈值断言脚本：统一产出 `lh-scores.json`，并按阈值失败退出。
- 新增本地一键 CI 脚本（PowerShell）：覆盖上述全链路，便于 Windows 环境复现。
