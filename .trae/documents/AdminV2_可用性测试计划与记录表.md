# 管理员后台 V2 可用性测试计划与记录表

## 1. 测试目标与指标
- 步骤减少 ≥ 30%
- 完成时间缩短 ≥ 50%
- 错误操作率 ≤ 1%
- 满意度 ≥ 4.5/5

## 2. 受试者与样本
- 建议：5~8 名受试者（覆盖 SuperAdmin/运营/商品/订单/审核/分析）
- 每个任务至少执行 3 次（不同受试者或同一受试者不同场景）

## 3. 任务脚本（建议）
T1：查询某用户并赋予“订单管理员”角色（含二次确认与原因填写）。  
T2：筛选“待发货订单”→ 完成发货（或状态更新）→ 验证审计日志产生。  
T3：筛选“售后待处理”→ 审批通过/拒绝 → 填写备注 → 验证状态变化与审计。  
T4：商品列表筛选某分类 + 关键词 → 选择多条 → 批量下架 → 导出 CSV。  
T5：查看近 7 天销售额趋势 → 导出报表。
