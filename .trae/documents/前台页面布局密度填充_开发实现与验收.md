# 前台页面布局密度填充：开发实现与验收

## 1. 变更范围
- 顶部导航：补充品牌标语与快捷入口（活动/指南/保障），并确保 hash 导航可用。
- 首页：主视觉轮播保留并收敛高度；新增“限时活动”锚点区（含实时数据+活动文案+用户动态），减少首屏后大块留白。
- 推荐页：新增筛选摘要 chips；未填写画像时提供示例配置一键填充并刷新结果。
- 购物车/个人中心：将前台页面的硬编码灰度色替换为全局 `--c-*` 令牌体系，保证风格一致与高对比模式可用。

## 2. 关键文件
- Header：`frontend/src/components/Header.vue`
- 首页：`frontend/src/views/Home.vue`、`frontend/src/components/home/HomeHeroCarousel.vue`
- 推荐页：`frontend/src/views/Recommendations.vue`
- 购物车：`frontend/src/views/Cart.vue`
- 个人中心：`frontend/src/views/UserCenter.vue`
- 路由 hash 滚动：`frontend/src/router/index.ts`

## 3. 页面级实现摘要
### 3.1 首页（/）
- `#campaign` 区：将实时数据卡纳入锚点区，补充活动文案与 CTA，并增加“用户动态”列表填充右侧空洞。
- 保留轮播：继续使用 SVG 轮播图作为高质量配图，且在 `prefers-reduced-motion` 下自动关闭自动播放。
- 性能测量：当 `?perf=1` 时输出 `home:renderDelayMs`（数据 ready → 双 rAF 后 UI 绘制）。

### 3.2 推荐页（/recommendations）
- 筛选摘要 chips：听损/预算/场景/品牌的可读信息密度增强。
- 空态示例配置：一键填充画像并刷新推荐，减少右侧空白与新手迷茫。
- 性能测量：当 `?perf=1` 且首次拿到结果时输出 `reco:renderDelayMs`。

### 3.3 购物车（/cart）与个人中心（/profile）
- 统一令牌：将 `bg-white/text-gray*/border-gray*` 等改为 `bg-[var(--c-*)]/text-[var(--c-*)]/border-[var(--c-border)]`，保证与首页一致并兼容高对比模式。

## 4. WCAG 2.1 AA 验收要点（与本次新增/改动相关）
- 键盘可达：新增按钮/链接均为原生可聚焦元素，命中区使用 `.a11y-hit`（≥48px）。
- 焦点可见：沿用全局 `:focus-visible`（3px outline），新增模块未覆盖。
- 对比度：前台尽量避免写死灰度色，统一使用 `--c-*` 令牌以保证高对比模式下可读。
- 状态播报：推荐结果更新已有 `aria-live`；实时数据区使用 `role="status" aria-live="polite"`。

## 5. 性能验收与复现步骤
### 5.1 Lighthouse
1) 构建：`cd frontend && npm run build`
2) 启动静态服务：`npm exec -- http-server dist -a 127.0.0.1 -p 4176 -c-1 --gzip --brotli`
3) 运行：
   `npm exec -- lighthouse http://127.0.0.1:4176/ --quiet --chrome-flags="--headless=new" --output=json --output-path=./lighthouse-report.json --only-categories=performance,accessibility --disable-storage-reset`

### 5.2 运行时埋点（用于 LCP/FID/CLS + 首屏渲染延迟）
- 打开：`http://localhost:5173/?perf=1`（或部署环境同理）
- 控制台会定期输出：`[perf] { lcpMs, cls, firstInputDelayMs, ... }`
- 首页/推荐页会额外输出：
  - `[perf] home:renderDelayMs <ms>`
  - `[perf] reco:renderDelayMs <ms>`

## 6. 兼容性说明
- 依赖均为现有栈（Vue3/Vite/Tailwind/Element Plus/lucide-vue-next），未引入新依赖。
- 新增内容为轻量文本/卡片/矢量图标，避免引入大图与视频资源，降低首屏回归风险。
