# 商城：可交互粒子封面入口页（页面设计）

> 设计原则：桌面优先（Desktop-first），保证 CTA 清晰、交互可学、过渡无跳变；性能优先以稳定 60fps 为目标。

## 1) 全局样式（Design Tokens / Global Styles）
- 背景色：#070A12（深色基底，减少屏闪）
- 主题色（CTA）：#5B8CFF；Hover：#7AA3FF；Pressed：#3E6BFF
- 文字色：主文 #FFFFFF；次文 #B8C0CC
- 字体：系统字体栈（优先），标题 28–40px，正文 14–16px
- 动效：过渡 220–320ms，优先使用 opacity/transform；避免 layout thrashing
- 链接：下划线仅在 hover 展示；焦点态使用 2px 主题色描边

## 2) 页面：粒子封面入口页（/cover）
### 2.1 Meta Information
- Title：进入商城｜品牌粒子封面
- Description：可交互粒子封面，支持跟随/散开/聚合，点击进入商城。
- Open Graph：og:title 同 Title；og:description 同上；og:type=website

### 2.2 Layout
- 布局：全屏层叠（Stacked Layers）
  - 底层：Canvas/WebGL 全屏渲染层（position: fixed; inset:0）
  - 上层：内容覆盖层（Flex 垂直居中 + 底部对齐 CTA 区）
- 间距：内容容器 max-width 1120px；左右 padding 24px；主要区块间距 16/24/32
- 响应式：
  - >=1024px：标题左对齐；CTA 与模式切换水平排布
  - <1024px：标题居中；CTA 置底固定，模式切换折行

### 2.3 Page Structure（从上到下）
1. 顶部导航（轻量）
   - 左侧：品牌名/LOGO（点击不跳转，避免误离开）
   - 右侧：文本按钮“跳过”= 进入主页（与主 CTA 同行为）
2. Hero 信息区
   - 标题：一句品牌/活动主张
   - 副标题：提示“移动鼠标/触控体验粒子效果”
3. 交互模式控制条
   - 分段控件：跟随 / 散开 / 聚合
   - 辅助提示：当前模式一句话说明（短文案）
4. CTA 区（主操作）
   - 主按钮：进入商城（Primary）
   - 次按钮：减少动态效果（当检测到 prefers-reduced-motion=off 时可隐藏；若 on，则显示“已降低动效”标签）
5. 性能提示（仅在降级触发时显示）
   - 轻提示条：如“已自动降低粒子数量以保持流畅” + “恢复默认”

### 2.4 Interaction States
- 按钮：Default / Hover / Pressed / Disabled（过渡仅用 opacity/transform）
- 模式切换：切换时显示 150ms 小提示（不遮挡 CTA）
- Loading：渲染未就绪时显示极简进度点/骨架；就绪后淡出（opacity 240ms）

### 2.5 Transition Guidelines（与主页）
- 从封面到主页：
  - 先锁定当前帧（或降低粒子运动强度）→ CTA 按钮缩放+淡出 → 背景渐变/遮罩过渡 → 路由切换
- 从主页返回封面：
  - 主页内容淡出 + 遮罩过渡 → 恢复封面（复用已加载资源）

## 3) 页面：商城主页（/）——与本需求相关部分
### 3.1 Meta Information
- Title：商城首页
- Description：商品浏览与活动入口。

### 3.2 Layout & Components（新增/调整）
- 顶部导航新增文本入口：返回封面（放在右侧次级链接区）
- 返回封面触发同样的遮罩过渡，避免“硬切”。
