# 后台管理页面设计（Desktop-first）

## Global Styles

* 布局基调：桌面端 1440px 内容宽度优先；后台采用 `左侧固定侧边栏 + 右侧内容区`。

* 视觉：浅色背景 `#F5F7FA`；内容卡片白底；主色沿用蓝色系（与前台一致）。

* 字体：系统字体栈；标题加粗；表格内容 14px。

* 组件建议：Element Plus（Menu/Table/Dialog/Form/Select/Pagination/Message/MessageBox）。

* 交互反馈：所有写操作成功/失败均 toast；删除/角色变更/状态变更需二次确认。

## 路由与页面结构（建议）

* `/admin`：后台 Layout + 默认展示“后台首页”。

* `/admin/users`：用户管理。

* `/admin/products`：商品管理。

* `/admin/orders`：订单管理。

> 入口与鉴权：进入上述路由前，前端应从本地存储读取 `access_token` 并在请求头携带 `Authorization: Bearer ...`；接口返回 401/403 时提示“无权限”并引导退出或回到前台。

## 1) 后台首页（/admin）

### Meta Information

* title：管理后台 - 概览

* description：查看平台关键运营数据与管理入口

### Layout

* CSS Grid：上方标题区 + 下方 2\~4 列统计卡片（随宽度折行）。

### Sections & Components

1. 顶部栏（可选）

   * 右侧显示当前管理员标识（邮箱/用户名）与“退出登录”。
2. 统计卡片区

   * 4 张卡片：用户数、商品数、订单数、累计销售额。

   * 数据来源：`GET /api/admin/stats`；支持“刷新”。
3. 快捷入口

   * 3 张入口卡/按钮：用户管理、商品管理、订单管理（点击跳转对应路由）。

***

## 2) 用户管理（/admin/users）

### Meta Information

* title：管理后台 - 用户管理

* description：查看用户列表并维护用户角色

### Layout

* 上方工具栏（筛选/刷新） + 主体表格 + 底部分页（如需）。

### Sections & Components

1. 工具栏

   * 主要按钮：刷新。
2. 用户表格（ElTable）

   * 列：用户名、邮箱、角色、创建时间、操作。

   * 操作：

     * “设为管理员/设为普通用户”（根据当前角色动态展示）。

     * 点击后弹出确认框 → 调用 `PUT /api/admin/users/:user_id/role` → 成功后就地更新该行。
3. 异常态

   * 401/403：显示无权限占位；提供“返回前台”。

***

## 3) 商品管理（/admin/products）

### Meta Information

* title：管理后台 - 商品管理

* description：维护商品信息与库存

### Layout

* 左对齐工具栏 + 表格列表；新增/编辑使用右侧抽屉或弹窗表单。

### Sections & Components

1. 工具栏

   * 分类筛选（Select，选项与前台分类一致）→ 触发重新加载列表。

   * 按钮：新增商品、刷新。
2. 商品表格（ElTable）

   * 列：商品图、名称、分类、价格、库存、操作。

   * 操作：编辑、删除。
3. 新增/编辑弹窗（ElDialog + ElForm）

   * 字段：name\*、category\*、price\*、stock\*、description、image\_url。

   * 提交：

     * 新增：`POST /api/admin/products`

     * 编辑：`PUT /api/admin/products/:product_id`

   * 成功：关闭弹窗 + 刷新列表。
4. 删除确认

   * 二次确认 → `DELETE /api/admin/products/:product_id` → 成功后刷新列表。
5. 列表数据来源

   * 列表读取：`GET /api/product/list?category=...`。

***

## 4) 订单管理（/admin/orders）

### Meta Information

* title：管理后台 - 订单管理

* description：查看订单、核对明细并更新订单状态

### Layout

* 工具栏（刷新） + 订单表格；订单明细使用行展开或弹窗。

### Sections & Components

1. 工具栏

   * 按钮：刷新。
2. 订单表格（ElTable）

   * 列：订单号、用户ID、金额、状态、创建时间、操作。

   * 操作：查看明细、修改状态。
3. 订单明细

   * 展开区/弹窗：items 列表（product\_id、quantity、price/name）。
4. 状态更新

   * 下拉选择（Select）：pending/paid/shipped/delivered/cancelled/completed。

   * 确认后调用 `PUT /api/admin/orders/:order_id/status`；成功后更新该行状态并提示。
5. 错误与空态

   * 空列表显示“暂无订单”；接口失败显示错误提示与重试按钮。
