# 助听器购物商城 —— 项目核心功能文件清单

## 项目概述

本项目是一个基于 **Flask + Vue3** 的助听器购物商城，包含前端商城、后台管理系统、用户设备管理、保养预约、个性化推荐等完整业务链路。

- **后端**：Flask + MongoDB + Redis + JWT
- **前端**：Vue3 + Vite + Pinia + Element Plus + Tailwind CSS
- **架构特点**：后端采用 Routes/Controllers → Services → DAOs → Models 分层设计；前端采用 Views → Stores → API 的数据流模式
