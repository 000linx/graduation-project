# GB/T 37668-2019 等级三自检清单（草案）

本清单用于内部自检与外部测评前准备，不等同于认证结论。

## 结构与语义

- [ ] 页面存在唯一主内容区域（main landmark）
- [ ] Header / Footer 语义明确，导航元素可识别
- [ ] 表单控件均具备可感知的名称（label/aria-label/placeholder 仅作补充）
- [ ] 图标按钮均具备可感知名称（aria-label/title）

## 键盘可达与焦点

- [ ] 全站可通过键盘完成主要操作（登录、搜索、加购、结算、个人中心）
- [ ] 焦点顺序符合视觉顺序，且无“焦点陷阱”
- [ ] `:focus-visible` 焦点样式清晰可见（对比明显、粗细≥2px）

## 视觉可访问（对比度/字号/缩放）

- [ ] 关键文本与背景对比度达到 WCAG 2.1 AAA（≥7:1）
- [ ] 提供一键大字体模式（基准字号≥18px）
- [ ] 支持 200% 放大且不丢失信息与功能（无重叠、无遮挡、无断行不可读）
- [ ] 可交互控件最小触控区域≥48×48（大字模式强制）

## 多感官提示（听障/无声场景）

- [ ] 关键状态变化不只依赖声音（成功/失败/加载/进行中均有视觉提示）
- [ ] 动态提示具备 ARIA-live 播报（辅助技术可即时获知）
- [ ] 视觉提示避免诱发风险（尊重 prefers-reduced-motion，闪烁次数受控）

## 语音与字幕（增强项）

- [ ] 语音输入可替代键盘输入完成核心任务（至少覆盖搜索场景）
- [ ] 语音识别过程提供实时字幕叠加（可关闭）
- [ ] 开启“语音播报”后，关键提示可 TTS 播报（可关闭）

## 表单与错误提示

- [ ] 错误提示可被读屏读到（ARIA-live 或 aria-describedby）
- [ ] 错误提示具备视觉高可见性（颜色+文案，不仅靠颜色区分）
- [ ] 输入错误给出可执行的纠正建议

## 测试与证据材料（建议）

- [ ] 产出任务脚本（核心任务≤3步：搜索→详情→加购、登录→个人中心→地址管理、购物车→结算→下单）
- [ ] 记录任务完成率与平均耗时（与改造前对照）
- [ ] 记录听障用户的“无声模式”成功率（关闭系统音量）
- [ ] 自动化回归：Vitest + Playwright 全量通过，并保存报告截图/录屏
